# 2026-07-17 Memory Flush

## bi_sales_delivery_notes Recursion Bug Fix
- **Issue:** Infinite recursion between `sale_order.py` and `stock_picking.py` when confirming a sale order. SO's `_update_delivery_notes_on_pickings()` writes to pickings, which triggers picking's `write()`, which writes back to SO, triggering SO's `write()` again → RecursionError.
- **Fix:** Added context flag `_bi_skip_delivery_note_sync=True` in both files to break the bidirectional sync loop. Applied to `sale_order.py` (SO→picking propagation) and `stock_picking.py` (picking→SO reverse propagation).
- **Files modified:** 
  - `inventory/bi_sales_delivery_notes/models/sale_order.py`
  - `inventory/bi_sales_delivery_notes/models/stock_picking.py`
- **Pushed to:** `stg` branch of `NioDigital/inventory`
